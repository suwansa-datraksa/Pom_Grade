## 1. ภาพรวมโครงสร้างแท็บใน Google Sheets

สเปรดชีตเป้าหมาย: [`1KcL20IBw5r36ODy9lcsBal6SmeZ9rRitctotZfwJKH4`](https://docs.google.com/spreadsheets/d/1KcL20IBw5r36ODy9lcsBal6SmeZ9rRitctotZfwJKH4/edit) ประกอบด้วยแท็บหลักดังนี้:

```text
[Index] ──► [Students] ──► [Room_4-1] ──► [Room_4-2] ──► [Protected_Keys] ──► [Raw_Scans]
(สารบัญ)    (ทะเบียน ID)    (คะแนน ม.4/1)   (คะแนน ม.4/2)      (เฉลยลับ)         (Log ดิบ)
```

1. **แท็บ `Students`:** ทะเบียนรหัสประจำตัว ชื่อ-นามสกุล ชั้น และเลขที่ (คุณครูกรอกข้อมูลนี้)
2. **แท็บ `Protected_Keys`:** ข้อมูลเฉลยข้อสอบ ค่าน้ำหนักคะแนน และจำนวนข้อ (คุณครูกรอกข้อมูลนี้)
3. **แท็บ `Raw_Scans`:** บันทึกประวัติการสแกนดิบแบบต่อท้าย (แอปมือถือและ Apps Script จะสร้างและบันทึกลงแท็บนี้)
4. **แท็บ `Index` และ `Room_XXX`:** Apps Script จะสร้างแท็บเหล่านี้ให้อัตโนมัติเมื่อมีการส่งผลสแกนครั้งแรก พร้อมผูกสูตรดึงคะแนนล่าสุดเรียงตามเลขที่

## 3. ข้อมูลจำลองสำหรับแท็บ `Protected_Keys` (เฉลยข้อสอบลับ)

### ข้อกำหนดสำคัญ:
* คอลัมน์ **A (ExamID)** และ **B (AnswerKey)** ต้องกำหนดรูปแบบเป็น **ข้อความธรรมดา (Plain text - `@`)**
* คอลัมน์ **Weights** คือค่าน้ำหนักคะแนนแต่ละข้อ คั่นด้วยเครื่องหมายจุลภาค `,` (หากเว้นว่างจะคิดข้อละ 1 คะแนนอัตโนมัติ)
* ตัวอักษรเฉลยต้องเป็นตัวพิมพ์ใหญ่ `A, B, C, D, E` หรือตัวเลข `0, 1, 2, 3, 4` (A=0, B=1, C=2, D=3, E=4)

### ตารางข้อมูลจำลอง (คัดลอกไปวางในเซลล์ A1 ของแท็บ `Protected_Keys`):

| :--- | :--- | :--- | :---: |
| EXAM_001 | A B C D A B C D A B C D A B C D A B C D | | 20 |
| EXAM_002 | A A B B C C D D A A B B C C D D A A B B C C D D A A B B C C D D A A B B C C D D | | 40 |
| PHYS40-2026A | A B C D D C B A A B C D D C B A A B C D A B C D D C B A A B C D D C B A A B C D | | 40 |

> *หมายเหตุ: ในช่อง AnswerKey ในตารางด้านบน ใส่ช่องว่างเพื่อให้อ่านง่าย ในชีตจริงให้เขียนติดกัน เช่น `ABCDABCDABCDABCDABCD`*

## 4. โครงสร้างแท็บ `Raw_Scans` (ฐานข้อมูลประวัติการสแกน)
