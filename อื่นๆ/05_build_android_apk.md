# คู่มือขั้นตอนที่ 5: การ Build ไฟล์ APK เพื่อติดตั้งลงโทรศัพท์จริง

> **Pom Grade — ระบบตรวจข้อสอบ OMR ไฮบริด (Architecture Specification v6)**  
> **จัดทำโดย ครูสุวรรณษา เดชรักษา**

---

เอกสารนี้อธิบายขั้นตอนการคอมไพล์และสร้างไฟล์ติดตั้ง **Android APK (`.apk`)** ของแอปตรวจข้อสอบ **Pom Grade Scanner** เพื่อนำไปติดตั้งและใช้งานจริงบนโทรศัพท์มือถือระบบ Android ของคุณครู

---

## 1. สิ่งที่ต้องเตรียมความพร้อมในเครื่องคอมพิวเตอร์
* **Android Studio:** เวอร์ชันล่าสุด (Hedgehog, Iguana, Jellyfish หรือใหม่กว่า) [ดาวน์โหลดที่นี่](https://developer.android.com/studio)
* **Java Development Kit (JDK):** เวอร์ชัน 17 (มีมาพร้อมกับ Android Studio อยู่แล้ว)
* **Android SDK:** รองรับ Android API 26 (Android 8.0) ถึง API 34 (Android 14)
* **โทรศัพท์มือถือ Android:** สำหรับติดตั้งแอป (ต้องมีกล้องหลังสำหรับสแกนกระดาษคำตอบ)

---

## 2. การเปิดโปรเจกต์ใน Android Studio

1. เปิดโปรแกรม **Android Studio**
2. ที่หน้าจอต้อนรับ คลิก **Open** (หรือไปที่เมนู `File` $\to$ `Open...`)
3. นำทางไปยังโฟลเดอร์แอป Android ในโปรเจกต์:
   ```text
   E:\Pom\Code\Pom Grade\android-scanner
   ```
4. คลิก **OK** เพื่อเปิดโปรเจกต์
5. รอให้โปรแกรมทำการดาวน์โหลดไลบรารีและ **Gradle Sync** ให้เสร็จสิ้น (จะเห็นแถบความคืบหน้าด้านล่างขวา เมื่อเสร็จจะขึ้นข้อความ `Gradle sync finished successfully`)

---

## 3. วิธีสร้างไฟล์ APK (เลือกได้ 2 วิธี)

---

### วิธีที่ A: สร้างแบบ Debug APK (รวดเร็วที่สุด เหมาะสำหรับทดสอบใช้งานทันที)

วิธีนี้ไม่ต้องสร้างไฟล์คีย์เซ็นชื่อใดๆ เหมาะสำหรับคุณครูนำไปติดตั้งทดสอบบนโทรศัพท์ทันที:

#### ทำผ่านเมนู Android Studio:
1. ที่แถบเมนูด้านบน คลิก **Build** $\to$ **Build Bundle(s) / APK(s)** $\to$ คลิก **Build APK(s)**
2. รอประมาณ 1–2 นาที เมื่อสร้างเสร็จ จะมีหน้าต่างแจ้งเตือนที่มุมล่างขวา:
   ```text
   Build APK(s): APK(s) generated successfully for 1 module(s).
   ```
3. คลิกที่คำว่า **`locate`** สีน้ำเงินในข้อความแจ้งเตือน เพื่อเปิดโฟลเดอร์ที่เก็บไฟล์ APK

#### หรือทำผ่าน Command Line (PowerShell):
```powershell
cd "E:\Pom\Code\Pom Grade\android-scanner"
.\gradlew assembleDebug
```

📁 **ตำแหน่งไฟล์ APK ที่ได้:**
```text
android-scanner/app/build/outputs/apk/debug/app-debug.apk
```
> ⭐ **ไฟล์ APK พร้อมติดตั้งสำหรับคุณครู:**  
> ระบบได้ทำการคอมไพล์และคัดลอกไฟล์มาไว้ให้ที่โฟลเดอร์หลักของโปรเจกต์แล้ว สามารถเปิดนำไปติดตั้งลงโทรศัพท์ได้ทันทีที่:  
> `E:\Pom\Code\Pom Grade\PomGrade_v1.0.0_debug.apk`

---

### วิธีที่ B: สร้างแบบ Release APK (พร้อม R8 Minify เพื่อความเร็วและความปลอดภัยสูงสุด)

วิธีนี้จะเปิดใช้งาน R8 Minify บีบอัดโค้ด ลบไฟล์ขยะ และเซ็นลายเซ็นดิจิทัลเพื่อประสิทธิภาพสูงสุด:

1. ที่เมนูด้านบน คลิก **Build** $\to$ **Generate Signed Bundle / APK...**
2. เลือกตัวเลือก **APK** $\to$ กด **Next**
3. ที่หัวข้อ **Key store path:**
   * หากยังไม่มีคีย์ ให้คลิก **Create new...**
   * เลือกที่เก็บไฟล์คีย์ (เช่น เก็บไว้ในเครื่องคอมพิวเตอร์) ตั้งชื่อ `pom-grade-release.jks`
   * ตั้งรหัสผ่าน (Password) และกรอกข้อมูล Alias
   * กด **OK**
4. กรอกรหัสผ่าน Key store และ Key password $\to$ กด **Next**
5. ในหน้า **Build Variants:**
   * เลือก **`release`**
   * ติ๊กถูกที่ช่อง **V1 (Jar Signature)** และ **V2 (Full APK Signature)**
6. กด **Finish**

📁 **ตำแหน่งไฟล์ APK ที่ได้:**
```text
android-scanner/app/build/outputs/apk/release/app-release.apk
```

## 4. ขั้นตอนการติดตั้งไฟล์ APK ลงบนโทรศัพท์มือถือ Android

คุณครูสามารถเลือกวิธีส่งไฟล์ APK เข้ามือถือได้ตามความสะดวก:

### ทางเลือกที่ 1: ติดตั้งผ่านสาย USB โดยตรง (ผ่าน Android Studio)
1. นำโทรศัพท์มือถือต่อสาย USB เข้ากับคอมพิวเตอร์
2. บนโทรศัพท์: เปิด **โหมดนักพัฒนา (Developer Options)** และเปิด **การดีบัก USB (USB Debugging)**
3. ใน Android Studio: ที่แถบด้านบนจะเห็นชื่อโทรศัพท์ของคุณครูปรากฏขึ้น
4. คลิกปุ่ม **Run (รูปสามเหลี่ยมสีเขียว ▶)** หรือกด `Shift + F10` แอปจะถูกติดตั้งและเปิดขึ้นบนโทรศัพท์ทันที

### ทางเลือกที่ 2: ถ่ายโอนไฟล์ APK ไปติดตั้งเอง (ง่ายที่สุด)
1. นำไฟล์ `app-debug.apk` ส่งเข้าโทรศัพท์มือถือผ่านทาง:
   * อัปโหลดขึ้น Google Drive แล้วเปิดดาวน์โหลดลงมือถือ
   * ส่งผ่านแอป LINE / เมลเข้าเครื่องตนเอง
   * หรือคัดลอกไฟล์ผ่านสายชาร์จ USB เข้าโฟลเดอร์ *Download* ของมือถือ
2. บนโทรศัพท์มือถือ: แตะที่ไฟล์ `app-debug.apk` เพื่อสั่งติดตั้ง
3. หากระบบเตือนว่า *"ไม่อนุญาตให้ติดตั้งแอปที่ไม่รู้จัก"* ให้แตะ **การตั้งค่า (Settings)** $\to$ เปิดสวิตช์ **อนุญาตจากแหล่งที่มานี้ (Allow from this source)**
4. แตะปุ่ม **ติดตั้ง (Install)**

## 5. การตั้งค่าและเริ่มใช้งานแอป Pom Grade ครั้งแรก

เมื่อเปิดแอป **Pom Grade** บนโทรศัพท์มือถือเป็นครั้งแรก:

```text
┌──────────────────────────────────────────────┐
│                  Pom Grade                   │
│   ระบบตรวจข้อสอบ OMR ความแม่นยำสูงระดับอัจฉริยะ   │
│   [แตะเพื่อลงชื่อเข้าใช้ Google (OAuth)]       │
├──────────────────────────────────────────────┤
│  รหัสข้อสอบปัจจุบัน: EXAM_001                 │
│  สแกนทั้งหมด: 0 แผ่น    | รอส่งขึ้นคลาวด์: 0     │
├──────────────────────────────────────────────┤
│  [  📷  เริ่มสแกนข้อสอบ                  ]   │
│  [  🔄  ซิงค์ข้อมูลกับคลาวด์             ]   │
│  [  📋  ดูประวัติการสแกน                 ]   │
│  [  ⚙️  การตั้งค่าระบบ                  ]   │
└──────────────────────────────────────────────┘
```

1. **การลงชื่อเข้าใช้ Google:**
   * แตะที่แถบสีน้ำเงิน **"แตะเพื่อลงชื่อเข้าใช้ Google (OAuth)"**
   * เลือกบัญชี Google ของคุณครู (บัญชีที่เป็นเจ้าของ Google Sheets)
   * เมื่อสำเร็จ แถบจะเปลี่ยนเป็นสีเขียว: `✓ บัญชี Google: your-email@...`
2. **การตั้งค่า URL ของ Apps Script:**
   * แตะปุ่ม **การตั้งค่าระบบ (Settings)**
   * ตรวจสอบ/กรอก **รหัสข้อสอบปัจจุบัน (Exam ID)** เช่น `EXAM_001`
   * กรอก **URL เว็บแอป Google Apps Script** ที่คัดลอกไว้จาก [คู่มือขั้นตอนที่ 1](file:///e:/Pom/Code/Pom%20Grade/อื่นๆ/01_deploy_google_apps_script.md)
   * แตะ **บันทึกการตั้งค่า**
3. **เริ่มสแกนข้อสอบ:**
   * แตะปุ่ม **เริ่มสแกนข้อสอบ**
   * อนุญาตให้แอปเข้าถึงกล้องถ่ายภาพ (Allow Camera Permission)
   * นำกล้องส่องไปยังกระดาษคำตอบ A4 ที่พิมพ์จากระบบ ให้จุดมุมทั้ง 4 จุดอยู่ในกรอบ (สังเกตกรอบมุมซ้ายบน TL จะเป็นสีส้มขนาด 14x14 มม.)
   * เมื่อจุดครบและกระดาษนิ่ง ระบบจะดัดระนาบ คำนวณรหัสนักเรียน ตรวจคำตอบ สั่นเตือน และบันทึกคะแนนพร้อมซิงค์ขึ้น Google Sheets อัตโนมัติทันทีครับ!
